# 🏍️ Gerador de Documentos - Oficina de Motos

## 📖 Sobre o Projeto
Esta é uma aplicação web desenvolvida para simplificar e automatizar a criação de documentos burocráticos, como certificados de compra e venda, para uma oficina de motocicletas. 

O objetivo principal é oferecer uma interface extremamente simples para usuários que não têm muita familiaridade com tecnologia. Em vez de editar textos corridos e correr o risco de desformatar o documento, o usuário preenche apenas os dados essenciais em um formulário limpo, e o sistema se encarrega de gerar o documento final pronto para impressão.

## ✨ Funcionalidades
* **Interface Focada em Usabilidade:** Layout limpo, de alto contraste e campos bem definidos para facilitar o preenchimento.
* **Validação Front-end:** Uso de TypeScript para garantir a estrutura correta dos dados (Nome, CPF/CNPJ, Placa, Chassi, etc.) antes do envio.
* **Geração Automatizada (Em desenvolvimento):** Comunicação com uma API Node.js para injetar os dados do formulário em um template de documento e retornar um arquivo PDF.

## 🛠️ Tecnologias Utilizadas
* **Front-end:** React.js
* **Linguagem:** TypeScript
* **Build Tool:** Vite
* **Estilização:** Tailwind CSS v4
* **Back-end (Planejado):** Node.js
